# turf

Turf-swift adapters (`TurfBridge`) and geometry modules (containment, area, length, buffer point, bounds geo).

Node barrel: `@local-hosting/geokit/core/turf`. Use **`BoundsGeo.getCenter`** for `@turf/center`-style centers on bounds, coordinates, and GeoJSON features.

Parity fixtures: `parity-fixtures.json`. See `docs/parity.md` and `docs/module-map.md`.
